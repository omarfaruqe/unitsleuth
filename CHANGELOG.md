# Changelog

## 0.1.2

- Fix overflow warning when computing posteriors for extreme rows.
- Smaller source distribution; usage guide, validation notes and citation metadata added.
- 0.1.1 exists only as a GitHub tag and Zenodo archive; its PyPI upload was skipped because the version number had not been bumped.

## 0.1.0

- Catalog of affine unit conversions (length, mass, temperature, volume, pressure, speed, time, ratios, power-of-ten errors).
- Univariate mixture detector with per-row posteriors and BIC-based evidence.
- Row-consistent multivariate detection and repair.
- pandas and Polars support through Narwhals.
- Command-line interface.
